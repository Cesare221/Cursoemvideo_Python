---

## 📚 Sobre o Curso

O Curso de Python 3 do **Curso em Vídeo** é composto por 3 mundos que abrangem desde o básico da linguagem até o uso de funções, módulos, pacotes e tratamento de erros.

- 🌍 **Mundo 1:** Fundamentos (primeiros passos, tipos primitivos, operadores, módulos, condições e repetições simples)
- 🌍 **Mundo 2:** Estruturas de Controle (condições aninhadas, laços `for`/`while`, interrupções)
- 🌍 **Mundo 3:** Estruturas Compostas (tuplas, listas, dicionários, funções, módulos, pacotes e tratamento de erros)
